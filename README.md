# Magnus

A 2D platforming game demo built from scratch to demonstrate core mechanics, game architecture, and rapid ability to learn new development environments.

[Play the Live Web Demo Here!] (https://dprieto12.github.io/magnus-unity/)

## Project Overview
* **Role:** Head Gameplay Programmer and Designer
* **Context:** First-Semester University Project (Completed over 4 weeks)
* **Engine & Tools:** Unity 6 (Version 6000.2.2f1), C#, Git
* **Status:** Complete / Production Build (v1.0.0)

## Core Objectives & Achievements
* **Rapid Tool Adaptability:** Transitioned from zero Unity and C# knowledge to a fully functioning game deployment in a compressed timeframe.
* **Component-Based Architecture:** Scripted player movement, hazard collisions, and UI state management using modular, reusable C# scripts
* **Game Design & Flow:** Designed a balanced tutorial level layout with satisfying visual feedback, camera framing, and responsive movement controls.

## Key Technical Implementations
* **State / Window Management:** Implemented methods to handle transitions between gameplay states, pausing, and scene reloads.
* **Responsive Platforming Physics:** Experimented heavily to craft custom physics parameters to smooth out bounding bugs and deliver quick and responsive platforming controls.
* **Polished UI System:** Designed interactive menu flows with custom script-driven event listeners for starting, pausing, and restarting loops.
